
# DevOps PetClinic Project

An end-to-end DevOps project using the Spring PetClinic application to demonstrate application containerization, deployment automation, cloud infrastructure, orchestration, and monitoring.

## Project Overview

This project uses the existing Spring PetClinic application and focuses on implementing real-world DevOps practices.

## Technology Stack

- Linux (Ubuntu)
- Git and GitHub
- Java 17
- Maven
- Docker
- Docker Compose
- GitHub Actions (planned)
- AWS (planned)
- Terraform (planned)
- Ansible (planned)
- Kubernetes (planned)
- Prometheus and Grafana (planned)

## Project Structure

```text
DevOps-Project/
├── application/
├── docker/
│   ├── Dockerfile
│   └── docker-compose.yml
├── terraform/
├── ansible/
├── kubernetes/
├── helm/
├── monitoring/
├── security/
├── scripts/
└── .github/
    └── workflows/
```

## Completed Work

- Configured Ubuntu using WSL2.
- Installed Git and Java 17.
- Built the Spring PetClinic application using Maven.
- Created a Dockerfile.
- Built a custom Docker image.
- Deployed the application using Docker.
- Configured Docker Compose.
- Verified container logs and resource usage.
- Created a Git repository and pushed the project to GitHub.

## Application Access

```text
http://localhost:8080
```

## Upcoming Implementations

1. GitHub Actions CI/CD pipeline.
2. AWS cloud deployment.
3. Infrastructure provisioning using Terraform.
4. Configuration management using Ansible.
5. Kubernetes deployment.
6. Helm charts.
7. Monitoring using Prometheus and Grafana.
8. Security and logging improvements.
